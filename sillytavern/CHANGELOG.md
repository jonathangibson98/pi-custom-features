# Changelog

## [1.19.1] - 03-11-2026

- Opens in the Home Assistant sidebar (ingress); direct access on port 8000 still works
- New option `log_level` (debug / info / warning / error)
- New option `extensions_plugins_path` to store extensions and plugins in `/config` or `/share` subfolders

## [1.19.0] - 03-11-2026

### Initial Release

- SillyTavern 1.19.0 built from the official `release` branch
- Admin password set from the add-on options
- Chats, characters, extensions and `config.yaml` stored in the add-on config folder
