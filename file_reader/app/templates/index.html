    How do I automate this? 
    1. Find your file in the list above and press "Automate".
2. Copy the code it shows into a Home Assistant automation
   (Settings > Automations > Add action > Edit in YAML).
3. Change the text in "payload" to whatever you want saved.

Each file also becomes a sensor. Its state is the time the file last
changed, and the text itself is in the sensor's "content" attribute.

Scripts outside Home Assistant can use the REST API instead
(see the Documentation tab).
