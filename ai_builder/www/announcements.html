Announcements

AI-written voice announcements. Each one is a Home Assistant script you can open, change and push again at any time, with an optional schedule.

Everything you've made

Import your script

Paste a Home Assistant script (YAML). It becomes an announcement here, so you can edit, push and run it from this add-on.

Works with just the script, the script with its id on top (the way it looks in scripts.yaml), or only the list of steps.

Leave blank to make a new script. Type the id of a script you already have in Home Assistant to take it over: pushing replaces it, and automations that call it keep working.
